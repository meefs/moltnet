# Landing Scripts Guide

Behavior for the landing page; `index.ts` is the single entry imported by
`src/pages/index.astro`.

- `content.ts`: shared copy (setup prompt, install command, terminal script).
- `scratch.ts`: hand-drawn strike over `h1 s`, revealed by an SVG mask.
- `terminals.ts`: the two-terminal loop; static transcript under reduced motion.
- `runtimes.ts`, `chrome.ts`: runtime cycling, copy/toast, GitHub stars.
